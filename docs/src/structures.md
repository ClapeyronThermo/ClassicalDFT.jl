# Structures

Every [`DFTSystem`](@ref ClassicalDFT.DFTSystem) needs a `structure`: the geometry, grid resolution, conditions and bulk densities the density profile is computed on. 
This page lists every concrete structure type. See [Choosing a Geometry & Adsorption](@ref) for guidance on which one to reach for.

## Single-Phase Structures

Used for a single bulk phase, typically next to an [external field](@ref "External Fields") (a wall, a pore, a solute) or on its own as a bulk-consistency check.

```@docs
ClassicalDFT.Uniform1DCart
ClassicalDFT.Uniform2DCart
ClassicalDFT.Uniform3DCart
ClassicalDFT.Uniform1DSphr
ClassicalDFT.Uniform1DCyl
```

## Two-Phase / Interface Structures

Used to resolve an interface between two bulk phases (vapour-liquid, liquid-liquid, or a microphase-separated copolymer melt), initialised as a sigmoidal density profile between the two supplied bulk densities. Not supported for [`SCFTSystem`](@ref ClassicalDFT.SCFTSystem) (see [SCFT](models/scft.md)) — SCFT has no two-phase/interfacial-tension machinery, and `SCFTSystem`'s constructor rejects these structures outright.

```@docs
ClassicalDFT.TwoPhase1DCart
ClassicalDFT.TwoPhase2DLamCart
ClassicalDFT.TwoPhase3DLamCart
ClassicalDFT.TwoPhase2DHexCart
ClassicalDFT.TwoPhase3DHexCart
ClassicalDFT.TwoPhase3DSphrCart
```

## Block-Copolymer Microphase Morphologies

Seed (and, via `initialize_profiles`, converge) a single periodic unit cell of a crystallographic microphase morphology, in which different named groups of one group-contribution component (see [Group-Contribution & Heterosegmented Chains](@ref)) enrich in different spatial domains — see [Copolymer Microphase Morphologies](@ref) for a
worked example. 
These structures also work directly with [`SCFTSystem`](@ref ClassicalDFT.SCFTSystem) (see [SCFT](models/scft.md)) — `initialize_profiles` dispatches to the same per-species-aware seeding either way.

```@docs
ClassicalDFT.LamellarStack1DCart
ClassicalDFT.LamellarStack2DCart
ClassicalDFT.LamellarStack3DCart
ClassicalDFT.HexLattice2DCart
ClassicalDFT.HexLattice3DCart
ClassicalDFT.BCC3DCart
ClassicalDFT.Gyroid3DCart
```
